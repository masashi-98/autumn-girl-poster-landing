# autumn-girl-poster-landing

This repository hosts the public page for a personal Google API application.

The application is used solely by its owner to back up the owner's own files to the owner's own Google Drive using [rclone](https://rclone.org/). It is not offered to, or intended for use by, anyone else.

## Privacy Policy

This application is used solely by its owner to back up files to the owner's own Google Drive via rclone.

- **No data collection:** The application does not collect, store, or analyze any personal information or user data.
- **No third-party sharing:** No data is sold, shared with, or provided to any third party.
- **Data access:** Access to Google Drive is used only to upload and manage the owner's own backup files, and data stays within the owner's own Google Drive.

## Contact

If you have any questions about this policy, please open an issue in this repository.
